    النتيجة النهائية

    توثيق API للمطورين

    جميع المسارات متاحة عبر CORS. أنشئ المهمة ثم ارفع الملفات إن وجدت، وبعدها نفّذ الدمج واستطلع حالة المهمة.

    إنشاء مهمة

    curl -X POST https://YOUR-DOMAIN/api/jobs \
 -H "Content-Type: application/json" \
 -d '{"videos":["https://host/a.mp4","https://host/b.mp4"]}'

    تنفيذ الدمج

    curl -X POST https://YOUR-DOMAIN/api/jobs/JOB_ID/process

    الحالة

    curl https://YOUR-DOMAIN/api/jobs/JOB_ID

    تحميل الفيديو

    curl -L "https://YOUR-DOMAIN/api/jobs/JOB_ID/video?download=1" -o merged.mp4

    حذف المهمة

    curl -X DELETE https://YOUR-DOMAIN/api/jobs/JOB_ID

    الحدود

    GET https://YOUR-DOMAIN/api/config
